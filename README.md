# Portfolio

My personal portfolio site. Single page, with a tag-filterable project grid, a carousel that handles screenshots and YouTube clips the same way, and a modal for anything with more to say than fits in the summary panel.

## Stack

- React 19 + TypeScript
- Tailwind CSS v4
- Vite
- Hono, for a small API worker
- Headless UI + Heroicons
- Deployed on Cloudflare Workers

## Running it locally

```bash
npm install
npm run dev
```

Runs at [http://localhost:5173](http://localhost:5173).

## Build and deploy

```bash
npm run build
npm run deploy
```
